## Research problem

Soil texture affects water availability, erosion, load-bearing behavior, and shrink–swell risk, but laboratory characterization is not always practical in the field.

## Contribution and methodology

This project combines reflectance multispectral imaging with machine-learning models to estimate clay, silt, and sand composition and classify the twelve USDA soil texture classes.

## Result

The resulting peer-reviewed study is published in *IEEE Access*. Its code is available in the linked repository. A suitable reusable project figure is not currently stored there, so the listing uses a text-only card.
