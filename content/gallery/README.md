# Adding gallery photographs

Create one folder per photograph inside `content/gallery/`, for example `content/gallery/hiking-memory/`. Add an `index.md` with `title`, optional `caption`, optional broad `location`, optional `year`, and `categories` such as `Hiking`, `Travel`, `Nature`, or `Memories`. Put one optimized image named `featured.webp` in the same folder.

Before publishing, remove GPS and unnecessary EXIF metadata. Use a broad public location rather than an exact private location. Export WebP at 2000–2400 pixels on the long edge and approximately 80–85 quality. The page intentionally renders an empty state until real photographs are added.
